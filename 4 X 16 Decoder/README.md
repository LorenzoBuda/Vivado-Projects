The purpose of this project was to create a 4 to 16 decoder with a 4 bit input, an enable input, and sixteen outputs. 
The input “[3:0] A”, represents a binary number from 0 to 15. 
When the enable switch “E” is HIGH, one of the output LEDs in “[15:0] Y” becomes HIGH based on the value of A. 
When the enable switch is LOW, all outputs are LOW.

# Vivado-Projects
Nexys A7-100T FPGA board was used to develop these projects

Vivado 2026 was used, so if using other versions, revisions to syntax might be needed.

The Nexys A7-100T FPGA board was used to test the code, so if using a different board syntax might need to be changed and the xdc file would need to match the FPGA board that would be used.
